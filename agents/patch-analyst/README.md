# Patch Analyst Agent

담당: 현아 ([@gusdkcjs4](https://github.com/gusdkcjs4))

## 역할

Collector Agent가 찾은 패치 커밋을 diff 단위로 분석합니다. 변경된 파일·클래스·메서드와 조건문(권한 검사, 입력값 검증 등)을 추출하고, "패치 전에는 없던 조건이 패치 후 추가됐다" 같은 근거로 취약점 발생 조건에 대한 가설(Hypothesis)을 생성합니다.

## 입력 / 출력

- 입력: Collector Agent가 만든 패치 커밋 JSON
- 출력: 변경 지점 요약 + 취약점 발생 조건 가설 (관찰 지점 포함)

## 검증 방법

3주차에 사람이 직접 만든 정답 데이터(수동 재현 기준선)와 비교해 정확도를 확인합니다.

## 진행 상태

- [ ] 패치 커밋 diff 파싱
- [ ] 조건문/권한검사/입력검증 변경 탐지
- [ ] 가설(Hypothesis) 생성 로직
- [ ] 정답 데이터 대비 정확도 비교
