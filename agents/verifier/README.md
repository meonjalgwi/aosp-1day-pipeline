# Verifier Agent

담당: 나연 ([@zv9uvr](https://github.com/zv9uvr)) — 7주차부터 통합·구현 단계에서 작업

## 역할

Executor Agent가 수집한 패치 전/후 실행 로그를 비교해 취약점 재현 여부를 자동 판정합니다. Agent의 판단이 실제 로그·diff에 근거하는지 검사합니다.

## 입력 / 출력

- 입력: 패치 전/후 실행 로그(logcat, 예외, 서비스 상태)
- 출력: 재현 성공/실패 판정 + 근거

## 진행 상태

- [ ] 패치 전후 로그 비교 로직
- [ ] 판정 근거 검증(로그·diff 기반인지 확인)
- [ ] 오탐/미탐 케이스 정리
