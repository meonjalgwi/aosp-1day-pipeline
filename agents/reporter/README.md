# Reporter Agent

담당: 나연 ([@zv9uvr](https://github.com/zv9uvr)) — 7주차부터 통합·구현 단계에서 작업

## 역할

Verifier Agent의 판정 결과와 근거 로그·diff·패치 커밋 링크를 모아 최종 분석 보고서를 HTML/Markdown 형태로 생성합니다.

## 입력 / 출력

- 입력: Verifier Agent의 판정 결과, 각 단계의 근거 자료
- 출력: HTML/Markdown 분석 보고서

## 진행 상태

- [ ] 보고서 템플릿 설계
- [ ] 근거 자료(로그/diff/링크) 자동 수집
- [ ] HTML/Markdown 출력 구현
