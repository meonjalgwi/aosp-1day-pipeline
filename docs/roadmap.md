## 대상 범위

- **지원 대상:** Android 보안 공지(2023~2025)에 AOSP 커밋 링크가 있는 패치 중 Java(P0)·Kotlin(P1) 코드 변경으로 결함을 고친 것
- **지원 대상 밖:** 네이티브·커널·비공개 수정, 리소스·설정만 바꾼 패치, 대규모 리팩터링 → 사유별 집계
- **후속 범위:** 동적 재현
- 기준선 CVE: **CVE-2023-40105 · CVE-2024-0037** (1주차 확정). CVE-2023-21113은 Development 데이터 겸 대체 기준선. 추가 후보: CVE-2024-0053 · CVE-2023-40111 · CVE-2023-40109

### 1주차 담당별 작업

| 담당 | 작업 | 산출물 |
| --- | --- | --- |
| A (서진) | CVE 데이터 정제·유형 커버리지: 기준선 2건 전·후 소스 확보(최우선), 후보 10건 재점검·상태 지정(`READY`/`NEEDS_WORK`/`HISTORICAL`/`EXCLUDED`), 부족 유형 추가 조사 | `cve_inventory.json`, `excluded_cases.json`, `type_coverage.md`, `sources/<CVE>/{before,after}/` |
| B (나연) | 수정 유형 분석·패턴 추출: 수동 정답, Tree-sitter 추출기, Guard 사전, 수정 유형 분류기 | `ground_truth.json`, `guard_dictionary.json`, `patterns/<CVE>.json`, 추출기 |

## 협업 규칙

1. 매 주차 시작 전 주차 이슈와 담당별 작업 이슈를 만들고 담당자를 배정합니다.
2. 이슈별로 브랜치를 만들어 작업합니다.
3. 작업 완료 후 PR을 생성하고, 팀원 최소 1명의 리뷰 승인을 받은 뒤 merge합니다.
4. PR 본문에 `Closes #작업이슈`(담당별 작업 이슈)와 `Refs #주차이슈`로 관련 이슈를 연결합니다.
